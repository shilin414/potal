## Execution Correctness Closure 修复（P0/P1/P2 全关，复核报告遗留项清零）

依据 `docs/potal 二次架构评测报告（Execution Correctness Hardening 复核）.md` 与
`docs/Creation Agent Studio Execution Correctness Closure 修复执行开发计划.md` 完成第二轮修复，
变更报告见 `docs/potal Execution Correctness Closure 修复变更报告.md`。

- **Ownership 拆分**：新增 `ExecutionOwnership` / `ClaimedRun` / `WorkerOwnedService`，Worker 只能拿 Owned 写面，
  `GetRun()` 刷新不再可能丢 lease token；迁移 0010 给 `run_leases` 加 `lease_epoch` 与 runs 对齐
- **Retry 状态机**：`RetryOwnedRun` 单事务（requeue + run.retrying + outbox + 删 lease）；
  终态集合收敛为 completed/failed/cancelled，`run.retrying` 非终态，前端保留 activeRunId 继续 streaming
- **Reaper 原子化**：`recoverExpiredLeaseTx` 单事务（锁 lease + 锁 run + epoch 校验 + requeue/fail + 事件 + outbox + 删 lease），
  `running + no lease` 窗口关闭
- **Finalize 事务**：`FinalizeOwnedRun` 单事务完成 terminal CAS + terminal RunEvent + assistant Message +
  occurrence terminal + lease 删除，Redis publish 后置
- **Artifact / Session fence**：`PersistArtifactOwned` 用真实 artifact id 发事件；`BindProviderSessionOwned`
  set-once / idempotent / conflict，stale worker 一律 ErrLostOwnership
- **Scheduler admission**：schedules 行 `FOR UPDATE` + `ORDER BY enqueued_at, id` FIFO + 单次 admit 一个
- **Admin auth**：`VerifyLocalAdmin` 强制 `is_staff || is_superuser`；admin/legacy 登录 5 次/5 分钟限流 + 审计；
  旧 `/api/auth/login/` deprecated + staff-only
- **P2**：新增 `cmd/invariant-checker`（A–G 七类 invariant）、`studio_execution_invariant_violation_total` /
  `studio_provider_limiter_degraded` 指标、Redis outage limiter 测试、backend/frontend GitHub Actions CI
- **测试**：新增 `correctness_closure_test.go` 覆盖 T1–T13；既有 fencing/CAS/outbox 测试同步迁移到新 API
- **回归**：`gofmt`、`go build`、`go vet`、`go test ./...`、
  `STUDIO_TEST_TIDB=1 STUDIO_TEST_REDIS=1 go test ./tests/integration/...`、`npm test`（115/115）、
  `npm run build` 全部通过；为满足 CI gofmt 门禁对 35 个 Go 文件做了机械格式化
- **环境坑**：集成测试曾被本机遗留的旧 studio-worker/scheduler/api 进程抢跑（共享 TiDB/Redis），
  杀掉后全绿；本机 pnpm shim 仍坏（MODULE_NOT_FOUND），前端回归直接用 npm（项目是 package-lock.json）
