### 5. .git 对象库事故（`git stash` 触发，历史全靠远程找回）
- 为"验证某个提交单独可构建"跑了 `git stash push -- <3 个已跟踪文件>` →
  `fatal: <sha> is not a valid object`，随后 `.git/refs/heads` 与 `refs/remotes` **整个目录消失**，
  `.git/objects/pack/*.pack` **被删只剩 .idx**（`in-pack: 0 packs: 0`），`git log` 报分支无提交。
- **工作区文件 6/6 完好**（这才是资产）；历史用 `git fetch origin` 全部找回。
- `packed-refs` 是 **CRLF** 会让引用名解析成 `…dev\r` → `ignoring ref with broken name …dev?`
  （`\r` 显示成 `?`），`for-each-ref` 一条都不列。重建引用**必须写 LF**。
- 索引里引用的 blob 也一起丢了 → `git commit` 报 `invalid object … for <path>`，

- push 后旧缺陷（远程已收到、本地 `[ahead 3]`）照例复现，补齐 loose + packed 后同步。
- 结论：**本机禁止 `git stash`**；需要"临时移除某些改动做验证"时，改用别的办法（见用户级记忆）。
